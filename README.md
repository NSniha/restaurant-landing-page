## Overview

**TasteNest** is a responsive **restaurant landing page** for a fast food brand, built with pure **HTML5, CSS3 and vanilla JavaScript**. There are no frameworks and no build tools, only clean and lightweight code that loads fast and is easy to edit.

The page presents the menu favorites, highlights daily deals, and shares the latest food stories, so visitors can quickly see what the restaurant offers. It works smoothly on phones, tablets and desktops.

You can use it as a **restaurant website template**, a **food business landing page**, or a **front-end practice project** for learning responsive web design.

## Key Features

- **Responsive layout:** works on mobile, tablet and desktop screens
- **Menu favorites:** burgers, crispy chicken, pizza and wraps presented clearly
- **Daily deals:** a dedicated area to highlight offers
- **Food stories:** a section for the latest news and stories
- **Bold visual style:** red brand color, strong typography and food-focused visuals
- **Icon set:** crisp vector icons with Ionicons
- **Fast and lightweight:** no heavy libraries, only HTML, CSS and JavaScript
- **Organized code:** separate `css`, `js` and `images` folders

## Getting Started

No installation or build step is needed.

**1. Clone the repository**

```bash
git clone https://github.com/NSniha/restaurant-landing-page.git
```

**2. Open the project folder**

```bash
cd restaurant-landing-page
```

**3. Run the website**

Open `index.html` in your browser, or use the **Live Server** extension in VS Code for automatic reloading while you edit.

---

## How To Customize

1. **Text and content:** edit the brand name, menu items and sections in `index.html`
2. **Colors and fonts:** change the styles in the `css` folder
3. **Images:** replace the pictures in the `images` folder with your own
4. **Behavior:** update the scripts in the `js` folder

## Deploy Your Website

You can put this site online for free:

- **Netlify:** drag and drop the project folder on [netlify.com](https://www.netlify.com)
- **Vercel:** import the repository on [vercel.com](https://vercel.com)
