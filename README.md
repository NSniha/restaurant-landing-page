## 📖 Overview

**Restaurant Landing Page** is a responsive **restaurant website** built with pure **HTML5, CSS3 and vanilla JavaScript**. No frameworks, no build tools: just clean, lightweight code that loads fast and is easy to edit.

The goal is simple: give a restaurant a great first impression online, show what they serve, and help visitors take the next step, whether that is checking the menu or getting in touch. It works on phones, tablets and desktops.

It can be used as a **restaurant website template**, a **cafe or food business landing page**, or a **front-end practice project** for learning responsive web design.

## 🚀 Getting Started

No installation or build step is needed.

**1. Clone the repository**

```bash
git clone https://github.com/NSniha/restaurant-landing-page.git
```

**2. Open the project folder**

```bash
cd restaurant-landing-page
```

**3. Run the website**

Open `index.html` in your browser, or use the **Live Server** extension in VS Code for automatic reloading while you edit.

---

## 🎨 How To Customize

1. **Text and content**: edit the text, restaurant name and menu items in `index.html`
2. **Colors and fonts**: change the styles in the `css` folder
3. **Images**: replace the pictures in the `images` folder with your own food photos
4. **Behavior**: update the scripts in the `js` folder

## 🌐 Deploy Your Website

You can put this site online for free:

- **GitHub Pages**: go to *Settings → Pages*, choose the `main` branch and save
- **Netlify**: drag and drop the project folder on [netlify.com](https://www.netlify.com)
- **Vercel**: import the repository on [vercel.com](https://vercel.com)

## ❓ FAQ

**Do I need Node.js or any framework?**
No. It is plain HTML, CSS and JavaScript. Just open `index.html`.

**Is it responsive?**
Yes, the layout adapts to mobile, tablet and desktop screens.

**Can I use it for my own restaurant or a client project?**
You can explore the code, learn from it and use it as a starting point. If it helps you, a ⭐ on the repo is always appreciated.
